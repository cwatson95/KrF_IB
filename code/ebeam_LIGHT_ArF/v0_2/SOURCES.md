# Sources (LIGHT_ArF)

This directory began as a copy of KrF's `LIGHT/v0_2`. Its KrF literature
stays in `LIGHT/v0_2/SOURCES.md`. LIGHT_ArF's sources are in
`../docs/arf_data/`:

- `SOURCES_CHECKED.md`: every number in `species.py` and `network.py`
  against its source, with the page and how it was read.
- `RATES_RESEARCH.md`: the ArF rate survey the network was built from.
- `SCORING_DATA.md`: the ArF measurements the model is scored against.

One row rests on the KrF reading. FF (F + F + Ar, (8.0 +- 0.6)e-35 cm6/s at
295 K) is Ganguli & Kaufman 1974 via Baulch et al. 1981 p.1-22, as quoted in
`LIGHT/v0_2/SOURCES.md` section 3. Baulch is not in the local library.
